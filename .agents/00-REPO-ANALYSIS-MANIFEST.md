# REPO MANIFEST & COMPLETE ANALYSIS OF 20 AI & DEV REPOSITORIES

Berikut adalah hasil analisis mendalam terhadap 20 repositori yang diminta, dikelompokkan berdasarkan fungsinya di industri AI & Software Engineering modern:

---

## 📑 1. DAFTAR LENGKAP & ANALISIS 20 REPOSITORI

### 🧠 A. AI Agent Frameworks & Orchestration
1. **[NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent)**
   - **Fungsi**: Runtime agent yang dioptimasi khusus untuk model open-weights *Hermes* (Nous Hermes 2/3).
   - **Fitur Utama**: Multi-turn tool/function calling, zero-shot structured tool execution, and local reasoning loops.

2. **[deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)**
   - **Fungsi**: Harness evaluasi dan testing suite resmi untuk keluarga model DeepSeek (V2, V3, Coder, R1).
   - **Fitur Utama**: Sandboxed code execution, benchmark metrics, and reasoning chain verification.

3. **[FoundationAgents/MetaGPT](https://github.com/FoundationAgents/MetaGPT)**
   - **Fungsi**: Framework Multi-Agent yang mensimulasikan struktur perusahaan software lengkap.
   - **Fitur Utama**: AI bertindak sebagai Product Manager (buat PRD), Architect (buat System Design), Project Manager (Task Breakdown), Engineer (Coding), dan QA (Testing).

4. **[bytedance/deer-flow](https://github.com/bytedance/deer-flow)**
   - **Fungsi**: Engine dataflow dan workflow orkestrasi skala besar dari ByteDance untuk pipeline multi-agent dan data processing dinamis.

5. **[ashishpatel26/500-AI-Agents-Projects](https://github.com/ashishpatel26/500-AI-Agents-Projects)**
   - **Fungsi**: Ensiklopedia arsitektur 500+ project AI agent nyata menggunakan LangChain, LangGraph, AutoGen, CrewAI, dan LlamaIndex.

---

### 🌐 B. Web Automation, Scraping, & Tools
6. **[firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)**
   - **Fungsi**: Web scraper & crawler engine canggih yang mengubah URL website apapun menjadi Markdown bersih yang ramah LLM.
   - **Fitur Utama**: Menghapus iklan, navigasi sampah, dan menangani render JavaScript dynamic secara otomatis.

7. **[browser-use/browser-use](https://github.com/browser-use/browser-use)**
   - **Fungsi**: Agent otonom yang dapat mengontrol browser secara langsung (klik, ketik, navigasi form, belanja online) menggunakan Playwright + Vision LLM.

8. **[google-gemini/gemini-cli](https://github.com/google-gemini/gemini-cli)**
   - **Fungsi**: Interface Command Line resmi untuk berinteraksi dengan Google Gemini API langsung dari terminal Linux/Windows/Mac.

9. **[ComposioHQ/awesome-claude-skills](https://github.com/ComposioHQ/awesome-claude-skills)**
   - **Fungsi**: Kurasi kumpulan toolkits, MCP (Model Context Protocol) servers, dan custom skills untuk Claude Code / Claude Desktop.

10. **[openclaw/openclaw](https://findarepo.com/repo/openclaw/openclaw/)**
    - **Fungsi**: Sandboxed agent harness otonom untuk eksekusi task modular dan persistensi context antar sesi.

---

### 🎨 C. Visual AI, Creative & UX/UI
11. **[Comfy-Org/ComfyUI](https://findarepo.com/repo/Comfy-Org/ComfyUI/)**
    - **Fungsi**: GUI berbasis node terkuat di dunia untuk AI Generatif Gambar/Video (Stable Diffusion, SDXL, Flux.1, ControlNet, IP-Adapter, AnimateDiff).
    - **Fitur Utama**: Workflow modular tanpa batas untuk kontrol presisi pada prompt, seed, denoise, inpainting, dan upscaling.

12. **[plugin87/ux-ui-agent-skills](https://github.com/plugin87/ux-ui-agent-skills)**
    - **Fungsi**: Kumpulan skill AI agent untuk analisis UX/UI, wireframing, audit aksesibilitas (WCAG), dan pembentukan design token.

13. **[miqdadbadjuber/anti-slop](https://github.com/miqdadbadjuber/anti-slop)**
    - **Fungsi**: Direktori instruksi dan prompt negatif untuk menghilangkan gaya penulisan dan kode generik "AI Slop" (basa-basi korporat, repetisi kata AI, template murahan).

---

### 📚 D. Knowledge, Prompt Engineering, & Foundations
14. **[dair-ai/Prompt-Engineering-Guide](https://github.com/dair-ai/Prompt-Engineering-Guide)**
    - **Fungsi**: Buku panduan terlengkap di dunia untuk teknik Prompt Engineering (Zero-shot, Few-shot, CoT, ReAct, Tree of Thoughts, Reflexion).

15. **[Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify)**
    - **Fungsi**: Framework Graph RAG untuk mengubah dokumen atau kode menjadi Knowledge Graph terstruktur guna meningkatkan akurasi retrieval LLM.

16. **[langchain-ai/langchain](https://github.com/langchain-ai/langchain)**
    - **Fungsi**: Framework standar industri untuk membangun aplikasi bertenaga LLM (Chains, Memory, Agents, Vector DB integrations).

17. **[rasbt/LLMs-from-scratch](https://github.com/rasbt/LLMs-from-scratch)**
    - **Fungsi**: Repositori edukasi legendaris oleh Sebastian Raschka yang mengajarkan cara coding LLM berbasis PyTorch dari nol (Tokenizer -> Attention -> Transformer -> Pretraining -> LoRA).

18. **[rohitg00/ai-engineering-from-scratch](https://findarepo.com/repo/rohitg00/ai-engineering-from-scratch/)**
    - **Fungsi**: Roadmap dan implementasi praktis AI Engineering end-to-end (Prompting, RAG, Fine-tuning, Evaluasi, Deployment).

19. **[freeCodeCamp/freeCodeCamp](https://findarepo.com/repo/freeCodeCamp/freeCodeCamp/)**
    - **Fungsi**: Repositori kurikulum belajar pemrograman open-source terbesar di dunia (Full Stack Web, Python, Security, Algorithms).

20. **[flutter/flutter](https://github.com/flutter/flutter)**
    - **Fungsi**: SDK multi-platform dari Google untuk membangun aplikasi native berkualitas tinggi di Android, iOS, Web, dan Desktop dari satu basis kode Dart.
